# SHL temporary lookbook PDFs (Nov 2026 trip)

Public on purpose: Heyzine converts a flipbook from a direct PDF link, so each cloud-built lookbook lands
here for a minute while Heyzine copies it. Heyzine keeps its own copy, so these files can be deleted
(or the whole repo removed) after Nov 11, 2026 without breaking any flipbook link.

Layout: lookbooks/<client-slug>-<YYYYMMDD>.pdf plus <client-slug>-<YYYYMMDD>-logo.png (the logo used).
